# Las tipografías

Las tres viven acá adentro y **no se piden a ningún servidor**. Es la única forma de
que el sistema ande en una máquina desconectada, y además una tipografía que llega de
un CDN también le cuenta a alguien que este equipo está mirando este legajo.

| Familia | Qué dice en la pantalla | Licencia |
|---|---|---|
| **Archivo** | la aplicación hablando: rótulos, botones, navegación | SIL Open Font License 1.1 |
| **Source Serif 4** | texto del documento y del escrito | SIL Open Font License 1.1 |
| **IBM Plex Mono** | un dato leído del papel: fojas, páginas, SHA-256 | SIL Open Font License 1.1 |

Las tres son OFL 1.1 y los textos de licencia están al lado de cada archivo, que es lo
que la licencia exige para redistribuirlas.

El porqué de que la familia tipográfica sea la que dice la procedencia del dato está en
[`docs/IDENTIDAD.md`](../../docs/IDENTIDAD.md).
